## Audit Criteria

### Q1 - Does the 4-type taxonomy separate standard physics from PF interpretation?

PASS.

Types 1-3 are now described as standard physical processes, while the observer taxonomy itself is marked as operational vocabulary. Type 4 is explicitly PF interpretation and OPEN. No Type 4 claim is promoted to canonical status.

### Q2 - Is the measurement problem left open?

PASS.

The file states that it does not determine whether collapse is physical, informational, or something else. It only defines the structural condition for an observation interaction: a state change producing a record/correlation. This is compatible with standard decoherence/relational language without claiming a foundational solution.

### Q3 - Does "now" follow SR/GR proper-time discipline?

PASS.

The canonical account uses an event on a timelike worldline labeled by accumulated proper time. The speculative local-causal-frontier picture is explicitly not required for the definition and remains tied to the open section of `time.md`.

### Q4 - Does the file imply consciousness is required?

PASS.

The definition explicitly says consciousness is not required. Type 4/self-correlating observation is open and does not derive subjective experience.
