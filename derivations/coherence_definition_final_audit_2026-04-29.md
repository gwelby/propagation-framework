## Acceptance Criteria

### 1. Definition is operational, not mystical

**PASS.**

The definition is:

> Coherence is stable relational structure among states under evolution.

This is operational. It identifies a relation among states, requires persistence under dynamics, and avoids undefined language such as harmony, resonance-as-feeling, or universal order.

### 2. Layer separation is explicit

**PASS.**

The table in `definitions/coherence.md` separates the main uses that were previously conflated. This is the core correction.

Downstream files must now name which layer they mean. That is the correct enforcement rule.

### 3. Axiom 3 boundary is honest

**PASS.**

The rewrite preserves the useful core:

> Stable structure requires coherent propagation. Incoherent modes disperse.

It also blocks overclaim:

- no exact particle-spectrum coherence functional,
- no universal threshold,
- no `Z3` selector,
- no coherence ceiling,
- no consciousness.

This matches the current truth order.

### 4. Quantum coherence is technically safe

**PASS.**

The file states basis dependence and off-diagonal density-matrix structure. It also distinguishes decoherence as suppression relative to an environment-selected pointer basis.

This is sufficient for a canonical workspace definition.

### 5. Applied biofeedback is separated from physics definition

**PASS.**

The P1 section now says applied proxies belong in P1 protocol files unless estimator, windowing, controls, and validation are specified.

This prevents live operational values from becoming physics definitions.

### 6. Consciousness is not smuggled into coherence

**PASS.**

The file explicitly says lasers, crystals, superconductors, and BECs are coherent without being conscious. It also says coherence is not sufficient for consciousness.

That closes the main category error.
