## 0. Status Grammar

This file does **not** create a second scoreboard.

Formal status still lives in `CLAIMS.md`.
When this note uses tighter prose buckets, they should map back to the repo taxonomy like this:

- **theorem island** -> usually `DERIVED`, sometimes `CONDITIONAL` if the missing bridge is named exactly
- **bridge** / **strong bridge** -> usually `ARGUED` or `CONDITIONAL`, never silently a closed theorem
- **empirical signal** -> `EMPIRICAL`
- **frontier** -> `INTUITION` or `OPEN`

Two extra caution words appear here on purpose:

- **model theorem** = a result that holds inside a named ansatz or restricted model; on the live board this should usually remain `CONDITIONAL` or `ARGUED`, with the model layer stated explicitly
- **metaphor / interpretation** = language that may help humans think, but does not upgrade claim status at all

If a sentence cannot be translated cleanly back into `CLAIMS.md`, it is not disciplined enough for this repo.

## 2. What I Do Not Trust

### 2.1 Any sentence that turns T1/T2/T3 into a finished theorem stack

Right now:

- T1 is **PARTIAL DERIVATION**
- T2 is **PARTIAL DERIVATION**
- T3 is **CONDITIONAL**

So any sentence that says “three generations are derived from topology” without naming the open numerator / denominator bridges is not careful enough.

### 2.2 Any sentence that says “all forces are refraction” as if that is already proved

The exact theorem is narrower.
When the repo blurs the narrow theorem into a total ontology, it stops being rigorous.

### 2.3 Any sentence that says the God Equation is closed because the number is good

The number is good.
That is not the same thing as the theorem being closed.

What remains open is not cosmetic:

- coherence-volume bridge
- operator/probability bridge
- `H_prod`

The IBM chirality result is evidence.
It is not closure.

### 2.4 Any sandbox script that explains more than it computes

The sandbox is useful when it is executable and narrow.
It becomes dangerous when the printed interpretation outruns the numbers.

Known example:

- `sandbox/chiral_projection_z3.py`

Known pattern:

- simulation support gets misread as theorem closure
