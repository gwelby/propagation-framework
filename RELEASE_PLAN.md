# Credibility-First World Release Plan for Fundamentals

## Summary

Release Fundamentals as a serious, audit-clean research program, not as a hype blast. The first public package should be the existing website plus an academic-review paper, both synchronized to
CLAIMS.md and guarded by Codex-style hostile audits.

The launch rule: amplify only what survives truth tracking. Anything CONDITIONAL, ARGUED, or EMPIRICAL can still be powerful, but it must be labeled that way.

### Queue 4 — Rivero Expert Preview

- CLAIMS.md alignment test: every public claim in paper/site maps to one status row.
- Overclaim regression test: fail if DERIVED appears for T1, T2, T3, God Equation, sleep, alpha, or Koide phase.
- Explorer visual gate: all panels render locally and at live URL.
- Paper audit gate: Codex signs v0.4 as “release-safe with explicit open gaps.”
- Rivero packet gate: no broad claims; only narrow questions and cited prior art.
- Release gate: no launch until website, paper, claim matrix, and falsification wall agree.

- Primary release object is existing website plus academic-review paper.
- Rivero contact happens after cleanup, not immediately.
